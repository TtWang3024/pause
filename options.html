Hold to Pause

Hold the left mouse button to count down before visiting blocked sites.

Saves groups, pause, background & break settings. Break activities and history save on their own.

Groups

Each group has its own pause length. Add sites as domains, one per line — subdomains match automatically (e.g. youtube.com covers m.youtube.com).

Countdown behavior

Off: releasing pauses the timer where it is. On: releasing snaps it back to full.

Pause page background

After completing a pause

Before each session you'll commit to a break length on a new screen — it always opens at the maximum, so you actively choose a shorter break each time.

Break activities

Predefine what you might do on a break. When a break starts you'll pick up to 3 of these (or add new ones on the spot). Drag the handle to reorder.
